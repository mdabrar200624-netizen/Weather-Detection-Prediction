\# 🌦️ Weather Detection \& Prediction



A machine learning based weather analysis application built using Python, Pandas, Scikit-learn, and Streamlit.



\## Features



\- 🌤️ Weather condition detection

\- 🌡️ Average temperature prediction

\- 📊 Historical temperature analysis

\- 🌧️ Historical rainfall analysis

\- 🤖 Machine learning model performance

\- 📈 Temperature model comparison



\## Technologies Used



\- Python

\- Pandas

\- NumPy

\- Scikit-learn

\- Joblib

\- Streamlit



\## Machine Learning Models



\### Weather Detection

Random Forest Classifier



Classes:

\- Sunny

\- Cloudy

\- Humid

\- Rainy



\### Temperature Prediction

The project compares multiple regression models and selects the best-performing model based on MAE, RMSE, and R² score.
